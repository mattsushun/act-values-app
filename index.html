Step 1/10 自動保存

このアプリでやること

あなたの価値観を、4つの物差し（勝利 / 信念 / 調和 / 自己決定）でレーダー表示します。
Step8（TOP3）とStep9（全価値観）で、行動例を見ながら自分の行動を書けて、例をワンタップで転記できます。

流れ： 質問 → ⭐ → Top5 → 順位 → 分類（推奨あり） → レーダー（統合のみ） → Step8 TOP3の一歩（例あり） → Step9 行動例＋自分の行動欄 → 終了/印刷

4つの軸

  • 勝利：成功を達成し、挑戦して克服すること
  • 信念：困難があっても、筋を通し続けること
  • 調和：バランスを保ち、平和な関係を維持すること
  • 自己決定：自律を行使し、自由に独立した選択をすること

操作

※入力は端末内保存（通信なし）。端末移動はJSONを書き出し。

質問に答える（今の傾向）

各質問に、今の自分に近い選択肢を1つ選んでください（全問回答で次へ）。

回答済み：0/0

⭐ 価値語にスターを付ける（30項目以内）

心に響くものに⭐。まずは広めに（10個以上推奨）。

⭐ 選択数：0

Top5に絞る

⭐を付けた中から、譲れない5個を選びます（ちょうど5個）。

Top5 選択数：0/5

順位付け（1位〜5位）

Top5の5つに、順位を割り当てます（重複不可）。

未割り当て：0

Top5を4軸へ分類（推奨あり）

各価値語が「最も満たされる軸」を1つ選びます（5個すべて選択で次へ）。

分類済み：0/5

まとめ：あなたの価値観レーダー（統合のみ）

質問（今の傾向）＋ Top5（順位＋分類）を統合して可視化します。

あなたへの読み取り

軸 統合（%）

TOP3：すぐにできる一歩（行動例つき）

上位3つの価値観に沿って、今日〜今週でできる小さな行動（5〜15分）を1つずつ書きます。
下に行動例（3つ）があり、ボタンで入力欄へ転記できます。

入力済み：0/3

行動例（全価値観）＋ 自分の行動を書く

価値観ごとに行動例（3つ）を表示し、自分の行動も書けます。
ボタンで例→自分の行動欄へコピーできます。
※TOP3の価値観は、ここで書いた内容がStep8（TOP3の一歩）にも反映されます（同じ入力データです）。

おすすめ：まずTOP3だけ開いて「例→コピー→少し自分用に修正」すると最速です。
※「その他（追加）」の価値観は、言葉の意味が人によって違うため、汎用テンプレ例を出します（必要なら自分用に言い換え）。

終了

保存は完了しています（この端末のブラウザ内）。タブを閉じれば終了です。
A4で印刷したい場合は下のボタンを使ってください。

ここからできること

ブラウザの仕様で、ボタンからタブを閉じられない場合があります。その場合は通常どおりタブ/ウィンドウを閉じてください。

データを完全に消す

この端末の保存データ（回答・選択・分類・行動）をすべて消去します。
